PACE funktioniert immer lokal. Google Sheets ist optional und synchronisiert Vorschläge und Tagesdaten.

Nicht verbunden. Lokale Speicherung ist aktiv.

Sheet öffnen ↗
Einmalige Google-Einrichtung
  1. In Google Cloud die Google Sheets API aktivieren.
  2. Einen OAuth-Client vom Typ Web application anlegen.
  3. Als autorisierten JavaScript-Ursprung https://david-bassler.github.io eintragen.
  4. Für lokales Testen zusätzlich z. B. http://localhost:8000.
  5. Die Client-ID oben eintragen. Kein Client Secret in diese App kopieren.

Installation

Auf Android kann PACE als App zum Startbildschirm hinzugefügt werden.
